## 🎯 Goal of the Day

The goal of **Day 11** is to understand the **core foundation of Object-Oriented Programming** and how real-world entities are mapped into Java using:

- Class
- Object
- Attributes
- Methods

This day focuses on thinking in **object-oriented way** instead of writing procedural code.

## 🧩 Real-World Mapping

Object-Oriented Programming is about representing real-world entities in code.

Real-world example:

Car → Class  
Specific car → Object

Car properties:

- color
- model
- speed

Car behaviour:

- start()
- stop()
- accelerate()

This mapping makes code:

- Reusable
- Modular
- Maintainable
- Scalable
