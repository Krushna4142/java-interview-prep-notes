## 🧩 Java Memory Connection

In Java:

- Primitive variables → stored in **Stack**
- Object references → stored in **Stack**
- Actual objects → stored in **Heap**

Example:

int a = 10; → Stack  
Student s = new Student();  
→ reference in Stack  
→ object in Heap

Understanding this is **critical for JVM-based interview questions**.
