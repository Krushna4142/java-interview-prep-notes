# Code of Conduct

This repository follows a simple principle:

Respect, kindness, and constructive collaboration.

## Expected Behavior

All contributors should:

• Be respectful and supportive
• Provide constructive feedback
• Encourage learning
• Maintain a professional tone

## Unacceptable Behavior

The following will not be tolerated:

• Harassment
• Disrespectful language
• Discriminatory comments
• Personal attacks

## Enforcement

Repository maintainers reserve the right to remove contributions or block users who violate this code.

The goal is to maintain a healthy learning environment.
