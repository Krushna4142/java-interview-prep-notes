## ⚙️ List vs Set – Core Differences

List:

- Allows duplicates
- Maintains insertion order
- Index-based access
- Used for ordered data

Set:

- Does not allow duplicates
- Not index-based
- Used for unique data
- Faster search (HashSet)

This decision-making is **frequently asked in interviews**.
