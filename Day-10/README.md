## 🔄 Control Flow Overview

Control statements change the **normal execution flow** of a program.

### Decision Making

- if
- if-else
- else-if ladder
- switch

### Looping

- for loop → fixed iterations
- while loop → condition-based
- do-while loop → executes at least once

### Branching

- break → terminates loop
- continue → skips current iteration

These are the **core tools for building program logic**.
