# Day 29 – Top 50 Java Backend Interview Questions & Answers

This file contains commonly asked **Java Backend Interview Questions** for quick revision.

---

# Core Java

1. What is Java?

Java is a high-level, object-oriented programming language designed to be platform independent using the JVM.

2. What are the main features of Java?

Platform independent  
Object oriented  
Secure  
Robust  
Multithreaded  
Portable

3. What is JVM?

JVM (Java Virtual Machine) is a runtime environment that executes Java bytecode.

4. What is JDK?

JDK (Java Development Kit) is a package that contains tools required for developing Java applications.

5. What is JRE?

JRE (Java Runtime Environment) provides libraries and JVM required to run Java programs.

---

# OOP Concepts

6. What is Object Oriented Programming?

Programming paradigm based on objects containing data and methods.

7. What are the four pillars of OOP?

Encapsulation  
Inheritance  
Polymorphism  
Abstraction

8. What is Encapsulation?

Wrapping data and methods into a single unit.

9. What is Inheritance?

A mechanism where one class acquires properties of another class.

10. What is Polymorphism?

Ability of an object to take multiple forms.

---

# Collections Framework

11. What is Java Collection Framework?

A framework that provides classes and interfaces to store and manipulate groups of objects.

12. Difference between List and Set?

List allows duplicates and maintains order.

Set does not allow duplicates.

13. What is Map?

Map stores key-value pairs.

14. What is HashMap?

HashMap stores data using hashing technique.

15. Difference between HashMap and Hashtable?

HashMap is not synchronized.

Hashtable is synchronized.

---

# Exception Handling

16. What is Exception?

An unwanted event that occurs during program execution.

17. What is Exception Handling?

Process of handling runtime errors.

18. What are checked exceptions?

Exceptions checked at compile time.

Example: IOException

19. What are unchecked exceptions?

Exceptions checked at runtime.

Example: NullPointerException

20. What is finally block?

A block that always executes after try-catch.

---

# Multithreading

21. What is a Thread?

A thread is the smallest unit of execution.

22. How to create a thread?

Extending Thread class  
Implementing Runnable interface

23. What is synchronization?

Process of controlling access to shared resources.

24. What is deadlock?

A situation where two threads wait for each other indefinitely.

25. What is thread safety?

Ensuring shared data is accessed safely by multiple threads.

---

# JVM Internals

26. What is Heap Memory?

Area where objects are stored.

27. What is Stack Memory?

Stores method calls and local variables.

28. What is Garbage Collection?

Process of removing unused objects from memory.

29. What is ClassLoader?

Loads class files into JVM.

30. What is JIT Compiler?

Converts bytecode to machine code during runtime.

---

# Spring Boot

31. What is Spring Boot?

Framework for building production-ready Java applications.

32. What is Dependency Injection?

Technique where objects receive dependencies from external sources.

33. What is REST API?

Architecture for building web services using HTTP methods.

34. What is @RestController?

Annotation used to create RESTful web controllers.

35. What is @Autowired?

Annotation used for dependency injection.

---

# Backend Architecture

36. What is MVC architecture?

Model View Controller design pattern.

37. What is Controller layer?

Handles HTTP requests.

38. What is Service layer?

Contains business logic.

39. What is Repository layer?

Communicates with the database.

40. What is layered architecture?

Application divided into separate logical layers.

---

# Advanced Backend Concepts

41. What is API?

Application Programming Interface used for communication between systems.

42. What is Microservices?

Architecture where applications are built as small independent services.

43. What is Monolithic architecture?

Application built as a single unit.

44. What is HTTP?

Protocol used for data communication on the web.

45. What are HTTP methods?

GET  
POST  
PUT  
DELETE

---

# Database Concepts

46. What is ORM?

Object Relational Mapping used to map Java objects to database tables.

47. What is JPA?

Java Persistence API for managing relational data.

48. What is Hibernate?

ORM framework implementing JPA.

49. What is Primary Key?

Unique identifier for database records.

50. What is Indexing?

Technique used to improve database query performance.
